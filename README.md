# سامانه مراکز خدمات روانشناسی و مشاوره «راه زندگی» — نسخه ۵.۰

بازنویسی کامل و مدرن سامانه مدیریت مراکز خدمات روانشناسی و مشاوره با تمرکز بر **تجربه کاربری (UX)** و **رابط کاربری (UI)** بهتر، سریع‌تر و قابل‌فهم‌تر.

> ⚠️ این مخزن **کد را شامل نمی‌شود** — کد کامل پس از بازبینی منتشر می‌شود.

## ✨ تغییرات نسبت به نسخه قبلی

| حوزه | نسخه قبلی (۴.۶۰) | نسخه جدید (۵.۰) |
|---|---|---|
| طراحی | Bootstrap 3، گرادیان‌های سنگین | طراحی مینیمال با Tailwind 4 و shadcn/ui |
| فونت | فونت‌های ناهمگون | **وزیرمتن** یکپارچه |
| تاریخ | چند فرمت ناهمگون | **تاریخ شمسی یکپارچه** در کل سامانه |
| اعداد | ارقام لاتین پراکنده | ارقام فارسی در همه‌جا |
| تم | فقط روشن | **روشن + تیره** با یک کلیک |
| موبایل | ضعیف | کاملاً ریسپانسیو (Mobile-First) |
| زنجیره تایید | پراکنده در چند صفحه | **خط زمانی بصری** داخل هر جلسه |
| پیمایش | بارگذاری کامل صفحه | پیمایش فوری بدون رفرش (SPA) |

## 🧩 ماژول‌ها

- **داشبورد** — شاخص‌های کلیدی، روند ۱۱ ماهه، توزیع خدمات، مصرف سهمیه‌ها، رزروهای پیش‌رو
- **تحلیل مدیریتی (BI)** — عملکرد استان‌ها، خدمات، مراکز برتر، سهمیه‌ها و موارد حاد
- **جلسات مشاوره** — لیست با فیلتر وضعیت، پرونده کامل جلسه، زنجیره تایید بصری (مدیر مرکز ← مسئول فنی ← نظارت حرفه‌ای ← ناظر استان ← ناظر کشور)، یادداشت‌های مشاور، فرم‌های بالینی، نوروفیدبک و داروها
- **جلسات گروهی** — گروه‌ها، جلسات و حضور اعضا
- **رزرو مشاوره** — رزروها به تفکیک مشاور و مراجع
- **ارجاعات سها** — پذیرش و پیگیری ارجاع‌های دریافتی از سامانه وزارت بهداشت
- **درخواست‌های رزرو کاربران** — تایید/رد با یک کلیک
- **موارد حاد (EMS)** — شدت‌بندی، جریان کمیسیون و پرداخت کمک‌هزینه
- **کاربران** — جستجوی پیشرفته، پرونده کامل، مسدودسازی، مدارک مشاوران
- **مراکز و کلینیک‌ها** — فعال/غیرفعال‌سازی، تفکیک استانی
- **نقش‌ها و دسترسی‌ها** — ۱۴ نقش سیستمی با تخصیص و تعلیق
- **قراردادهای سازمانی** — مشتریان سازمانی و جدول تعرفه ۵ سطح مشاور
- **سهمیه‌های خدماتی** — سقف، مصرف، رزرو و تخصیص استانی
- **عملکرد مالی** — تفکیک درآمد (مشاور، نظارت، مرکز، مدیریت، دبیرخانه)
- **مالیات مشاوران** — دوره‌ای ماهانه با نرخ مؤثر
- **پیامک‌ها** — گزارش وضعیت و ارسال گروهی بر اساس نقش/استان
- **پیام‌های داخلی** — صندوق ورودی/ارسالی با ستاره‌گذاری
- **لاگ فعالیت** — سطح‌بندی اطلاعات/هشدار/خطا
- **تنظیمات، مناسبت‌ها، تیکت پشتیبانی و راهنما**

## 🛠 پشته فناوری

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS 4** + **shadcn/ui** + فونت **وزیرمتن**
- **Prisma ORM** (SQLite برای توسعه / MySQL برای تولید)
- **Recharts** برای نمودارها + **next-themes** برای تم تیره/روشن

## 🚀 راه‌اندازی

```bash
# ۱) نصب وابستگی‌ها
bun install   # یا npm install

# ۲) تنظیم دیتابیس توسعه (SQLite)
#    فایل .env:
DATABASE_URL="file:./db/custom.db"

# ۳) ایجاد جداول
bun run db:push

# ۴) داده اولیه نمونه (۱۱۶ کاربر، ۲۲۰ جلسه و...)
bun prisma/seed.ts

# ۵) اجرا
bun run dev   # http://localhost:3000
```

### حساب‌های نمونه (رمز همه: `123456`)

| نقش | نام کاربری |
|---|---|
| مدیر سیستم | `admin` |
| مدیر کلینیک | `1210000016` |

> در داده نمونه، نام کاربری بقیه کاربران برابر کد ملی است.

## 🐬 استقرار روی MySQL واقعی

اسکیمای Prisma عمداً با انواع پرتابل نوشته شده تا با تغییر فقط provider روی MySQL واقعی مستقر شود:

```bash
# ۱) فایل .env پروduktion:
DATABASE_URL="mysql://USER:PASS@HOST:3306/DBNAME"

# ۲) استفاده از اسکیمای MySQL:
cp prisma/schema.mysql.prisma prisma/schema.prisma   # یا:
prisma db push --schema prisma/schema.mysql.prisma
```

ساختار جداول (Users، Events، Centers، Referrs، EventsEms، ConsultantTax، ...) آینه‌ای از بکاپ واقعی `app2_backup` است؛ فیلدهای JSON به String و Decimal به Float نگاشت شده تا بین دو دیتابیس سازگار بماند.

## 📁 ساختار

```
prisma/            اسکیما (SQLite/MySQL) + Seed
src/app/api/       API Route ها (auth, dashboard, events, ...)
src/components/    پوسته اپ، کامپوننت‌های مشترک و نمودارها
src/views/         ۲۳ نمای ماژول (داشبورد تا تنظیمات)
src/lib/           تاریخ شمسی، احراز هویت، کلاینت API
```

## 🔐 نکات امنیتی

- رمزها با scrypt هش می‌شوند؛ نشست‌ها در جدول `Sessions` با کوکی httpOnly نگهداری می‌شوند.
- زنجیره تایید جلسات بر اساس نقش کاربر کنترل می‌شود.
- قبل از استقرار واقعی، اتصال به دیتابیس MySQL موجود و انتقال کاربران بررسی شود.
